# Interview Prep — Phase by Phase

Each `phase-N.md` file is written **after** that phase's feature branch is merged into `development` — never before, so the content always matches what was actually built.

Every phase file follows the same structure:

1. **What was built** — scope of the phase, mapped to the feature IDs in `planning.md` §3
2. **Approach used and why**
3. **Technology used and why** (vs. the alternatives considered)
4. **Alternative approaches** that were rejected, and the trade-off
5. **Expected interview questions** — conceptual
6. **Scenario-based questions** — "what happens if X fails", "how would you change this for Y scale"
